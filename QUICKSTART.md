# Quick Start Guide / クイックスタートガイド

## Installation / インストール

### Option 1: Direct Use (Recommended for Students)
Simply open `index.html` in your web browser:
1. Download or clone this repository
2. Navigate to the folder
3. Double-click `index.html`
4. Start designing!

### Option 2: Using a Web Server
For better performance and full features:

**Python:**
```bash
python3 -m http.server 8080
```
Then open: http://localhost:8080

**Node.js:**
```bash
npx http-server -p 8080
```
Then open: http://localhost:8080

## System Requirements / システム要件

- Modern web browser (Chrome, Firefox, Safari, Edge)
- JavaScript enabled
- WebGL support (built into most modern browsers)
- No installation required!

## First Steps / 最初のステップ

1. **Create a Shape (形を作成)**
   - Click "Rectangle", "Circle", or "Polygon"
   - A 2D shape will appear on the grid

2. **Extrude to 3D (3Dに押し出し)**
   - Select the shape (click on it)
   - Set the extrusion height
   - Click "Extrude to 3D"

3. **Customize (カスタマイズ)**
   - Change colors using the color picker
   - Use transform tools (Move, Rotate, Scale)
   - Position objects with arrow keys

4. **Save Your Work (作品を保存)**
   - Click "Export Design"
   - Save the JSON file
   - (Future: Import feature coming soon!)

## Troubleshooting / トラブルシューティング

**3D scene not showing?**
- Make sure JavaScript is enabled
- Check if your browser supports WebGL
- Try a different browser (Chrome recommended)

**Controls not working?**
- Make sure you clicked on the canvas area
- Try refreshing the page
- Check browser console for errors (F12)

**Objects not visible?**
- Use "Reset Camera" to return to default view
- Try zooming out with scroll wheel
- Toggle grid on/off to see the workspace better

## Learning Path / 学習パス

### Beginner (初級)
1. Create simple 2D shapes
2. Extrude them to 3D
3. Change colors
4. Export your first design

### Intermediate (中級)
1. Create multiple objects
2. Use transform tools
3. Build simple structures (e.g., a table, chair)
4. Practice camera controls

### Advanced (上級)
1. Design complex assemblies
2. Create realistic wooden frames
3. Plan actual woodworking projects
4. Use precise measurements with extrusion heights

## Educational Use / 教育での使用

This tool is designed for:
- **Technology Classes (技術の授業)**: Learn 3D design concepts
- **Woodworking Projects (木工プロジェクト)**: Plan before building
- **Spatial Reasoning (空間認識)**: Understand 2D to 3D transformation
- **STEM Education**: Apply math and geometry concepts

## Tips for Teachers / 教師向けのヒント

1. Start with simple shapes and gradually increase complexity
2. Have students sketch on paper first, then recreate in 3D
3. Use the export feature to save and share student work
4. Challenge students to recreate real objects they see in class
5. Discuss measurements, proportions, and spatial relationships
